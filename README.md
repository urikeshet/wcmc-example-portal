# WCMC Example Data Portal

An example interactive metabolomics data portal from the UC Davis West Coast Metabolomics Center (WCMC), built with the WCMC data portal builder. It shows an internal example study (human urine, plasma and food smoothies; participants coded P-1, P-2, ...).

Live: https://urikeshet.github.io/wcmc-example-portal/

`index.html` is self-contained (app, plots and data inline) and is published unchanged from the builder output.

`media/` holds the hero video and poster for the WCMC homepage.
